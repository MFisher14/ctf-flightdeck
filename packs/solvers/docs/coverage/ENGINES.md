# Engine coverage matrix

Generated by `python -m ctf engines coverage --write` from the engine manifests
(`<module>.manifest.toml`) and the test files. Do not edit by hand:
`tests/test_engines_coverage.py` fails when this file is stale. After a merge that touches
engines, regenerate it instead of resolving conflicts line by line.

- **class**: `executes` (a CLI that scans its output for flags), `analysis` (a CLI that reports
  facts), `plan` (builds candidates, never runs them), `library` (import-only; `ctf run` refuses
  it). Inferred for the carried engines (ctf/engines/generate.py); a manifest can correct it.
- **routes**: the categories its `[[routes]]` name; `any` = a keyword route valid in every
  category; `UNROUTED` = triage never suggests it.
- **tests**: test files that import the module or name its path. 0 = no test reaches it.
- Real use in play is not here: each run of `ctf run` / `ctfpy` appends `engine.run` to the event
  ledger; `python -m ctf engines usage` reports it.
