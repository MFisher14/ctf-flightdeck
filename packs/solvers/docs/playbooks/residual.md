# Residual playbook: shapes no solver closes (B-254)

Generated by `python -m ctf residual playbook --write` from `ctf/residual.py`; do not edit by hand.

These classes have no machine-checkable oracle: the answer is the author's or the judge's own
vocabulary, or the input carries too little information. The correct engine output is `unsure`
or `none`, never a forced plain answer (`ctf residual check` and `ctf residual hold` enforce it).
Once an id is marked residual, the submit gate refuses a plain value on it unless the player says
go (`confirmed=True`): that is how the class's one bounded probe goes out.
The win condition is that almost nothing is novel (`ctf residual report` measures it per event),
not that novelty is instant: measured novelty is 2:44 to 4:00 with foreknowledge, 5 to 20 min blind.

The handoff is B-151's shape: a structured finding with `residual_class`, `challenge_id`, `evidence`, `likely_shape`, `controls_tried`, `bounded_next_probe` (`ctf residual template <class> --id <id>`, then `ctf residual mark FILE`). A residual id that
keeps drawing rejections goes through the stuck-id protocol (B-203): `ctf residual stuck <id>`.

## One line per class

- **`warmups.lossy_or_unstated_key`** (Warmups: lossy transform or unstated key): Look for the key or alphabet stated elsewhere (title, hint, file name); if two complete readings survive, offer both as unsure options and never pick one plain.
- **`mobile.opaque_codec`** (Mobile: opaque codec or device-dependent state): Name the opaque step (native method, split selector, keystore alias) and read it statically; trust a new reader only when its output fullmatches a second, independent sample.
- **`metadata.new_vocabulary`** (Metadata: new author vocabulary or ambiguous container): Read the field with the closest reader and offer its spellings as unsure options; spend judge probes on the untimed base only, under the stuck-id cap.
- **`binary.unjudged_enum`** (Binary: new runtime semantic or unjudged structural enum): Disassemble statically, trace the indirect flow to one concrete value, and offer the enum's candidate names as unsure options until the judge accepts one.
- **`script.unproved_descriptor`** (Script: unproved descriptor or dynamic mutation): Prove the descriptor by two independent copies agreeing; trace the mutation by hand to a complete plan witness; until then the reading stays unsure.
- **`web.unproved_effect`** (Web: an effect with no proving response): Stop at a structured finding (solvers/web/agent_handoff.py template <class>), set a control, then run the one bounded probe whose response or OOB callback proves the effect.

## Detail

### `warmups.lossy_or_unstated_key`: Warmups: lossy transform or unstated key

- Shapes: a lossy transform that erases symbols never seen in the input; an unstated square, alphabet or key; two complete, distinct readings; an input-dependent or non-terminating program.
- No oracle: the input carries too little information: the erased symbols or the key are not in the files, or two complete readings both fit.
- Cold stops at: unsure with every complete reading as an option; none when no reading completes.
- Controls: the same reader on a sibling warmup whose key is known; the reading count: one complete reading is not this class.
- Bounded next probe: one judged probe of the top-ranked reading on the untimed base, never on a running clock.
- Never: never send one of two complete readings plain; never brute-force keys against the judge.

### `mobile.opaque_codec`: Mobile: opaque codec or device-dependent state

- Shapes: a new opaque codec; native, JNI or ART semantics no reader implements; a split chosen by device state; a secret held only in the hardware keystore; a multiply repairable ZIP.
- No oracle: the decoding lives in native code or device state that static readers cannot prove, and a hardware-keystore secret never leaves the device.
- Cold stops at: unsure naming the opaque step; none when nothing decodes.
- Controls: the codec's output on a string-table entry whose plaintext is known; which split a stock device profile selects.
- Bounded next probe: decode one known-plaintext entry through the candidate codec and compare it byte for byte.
- Never: never run or emulate the app or its native code on the host; never choose one repair of a multiply repairable ZIP.

### `metadata.new_vocabulary`: Metadata: new author vocabulary or ambiguous container

- Shapes: genuinely new author vocabulary; an encrypted member with no password given; a multiply repairable container; filesystem allocation semantics no reader implements.
- No oracle: the answer is the author's or the judge's own label: no byte-level check proves the spelling.
- Cold stops at: unsure with the closest reader's spellings as options; none when no field is read.
- Controls: the closest reader's output on a sample whose label the judge accepted; the spellings already rejected (the hypothesis ledger).
- Bounded next probe: one judge probe of the top-ranked spelling on the untimed base, recorded in the hypothesis ledger.
- Never: never send an unjudged label plain; never fold a label the judge has not accepted.

### `binary.unjudged_enum`: Binary: new runtime semantic or unjudged structural enum

- Shapes: a new architecture or runtime that needs a semantic adapter; complex or indirect native control flow; an author-named structural enum with no judged name.
- No oracle: the value or name depends on semantics no adapter models, or on a name only the judge can accept.
- Cold stops at: unsure with the candidate names or values as options; none when the flow is not resolved.
- Controls: the same trace on a sibling sample whose answer was accepted; a CRC or checksum in the file that a reading must satisfy, when there is one.
- Bounded next probe: one judge probe of the top-ranked name on the untimed base.
- Never: never execute the challenge binary; never send an unjudged enum name plain.

### `script.unproved_descriptor`: Script: unproved descriptor or dynamic mutation

- Shapes: an unproved whole descriptor; dynamic or interprocedural mutation; a new host with no complete plan witness.
- No oracle: no witness proves the whole plan: the mutation happens at run time or across procedures.
- Cold stops at: unsure with the partial plan; none when no descriptor is read.
- Controls: the two-copy agreement on a sample whose plan is known; the host's own interpreter rules, read from its documentation, not by running the script.
- Bounded next probe: decode one more independent copy of the descriptor and compare it with the first.
- Never: never run the challenge script; never send a reading that only one copy supports.

### `web.unproved_effect`: Web: an effect with no proving response

- Shapes: a write, state change or out-of-band action that no response proves.
- No oracle: the effect happens where the response does not show it, so no reply can confirm it.
- Cold stops at: unsure with a structured finding (B-151); none when no effect is observed.
- Controls: the same request against a control the effect cannot touch; an out-of-band listener the scope allows.
- Bounded next probe: the one bounded probe the B-151 playbook names for the class.
- Never: never fire a state-changing request without the player's go; never call an unproven effect solved.
